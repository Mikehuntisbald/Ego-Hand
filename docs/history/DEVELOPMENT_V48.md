# v48 持续训练与已恢复点保护

2026-10-05。已完成对照验证的DiT基准主权重来自v43（选中3000步）；v44–v46沿用该权重，改变采样窗口和运动约束。视觉与三维时序核心联训从v47开始，v48是续训实验，包含冻结对照；尚未完成证明联训版优于v43的完整比较。

`CURRENT_PIPELINE.json`入口仍指向v42，这是默认配置状态，不是实验性能排名。v47已跑完600步，视觉联训有实际权重更新，但好点损坏未通过准入。本轮结果以 `ONLINE_RGB_V48_STATUS.json` 和报告为准，训练启动不代表效果提升。

## 遇到的问题与处理

| 问题 | 处理 |
|---|---|
| 平均误差下降，但原WiLoR好点损坏超出1%门槛 | 保留门槛；续训学习率降到头5e-6、视觉2e-7，继续相同数据和对照 |
| 原保护损失没有覆盖时序模型已经修好的点 | 固定已准入教师，在训练标签中找误差≤10mm点；FK输出超出教师误差+1mm时增加hinge损失，权重4。教师不进入推理 |
| 训练集相对坐标有3374个教师好点没被原保护覆盖 | 用新保护补齐这类点；这是损失覆盖缺口的证据，尚不是性能提升的证据 |
| v47没有保存优化器，不能严格恢复原训练轨迹 | 明示权重续训＋优化器重启；v48保存参数、视觉尾层、Adam状态、CPU/CUDA/NumPy随机状态和批次计划 |
| 把未通过准入的last.pt当作best会掩盖损坏 | best.pt先保留真正已准入教师；best_trained.pt和last.pt独立保存；训练权重通过全部门槛才进入best |
| GPU3被其他任务临时占用 | 后台控制器检查进程，排队至GPU3空闲；不结束或抢占其他项目 |
| 初次梯度检查误选旧的head.weight，而它在语义参数模型中被冻结 | 改查实际输出的semantic_head.weight；保留原错误日志，再验证保护项本身的梯度 |
| 未触发hinge的样本保护梯度为零，预检查误判失败 | 选教师好点充分的自然样本，记录自然梯度；额外仅在梯度诊断中平移FK输出以触发惩罚。没有改训练图片、标签或损失 |
| 自动跟进文本经本地Python默认编码转存后损坏 | 改用ASCII英文保存持续执行指令，元数据通过ASCII JSON传递；恢复中文任务名，用户报告仍用中文 |

## 本轮固定对照

- frozen：延续v47冻结主干600步权重，时序头续训1800步。
- joint：延续v47视觉联训600步权重，最后4层/Norm与时序头续训1800步。
- protected：与joint相同起点、批次、学习率与训练预算，仅增加教师好点保护。

三组累计2400步。有效批量4（2×累积2），每100步验证并保存可恢复断点。真实RGB，无人工遮挡。2526训练中心、352重复开发中心；未把dev_calibrate拿来调参。

保留32层WiLoR视觉主干，0–27层冻结，28–31层与last_norm可训练；保留原生192×1280空间token。非causal窗口最多±1.6秒。DiT输出受限的UmeTrack兼容手参数，经可微FK输出3D；YOLO/跟踪、原WiLoR关键点与200步IK初值固定，候选选择和350步稳定器仍在反向传播图外。它是重建核心联训，不是整条检测流水线端到端。

速度限制保持不变；根位置/相对手形/腕旋转/关节的加速度软、硬限制都沿用×2配置。没有通过改速度门槛换取更好数字。

## 验证与选型

预检查验证推理GT污染不改变输出、继承模型推理结构/权重严格一致、教师保护对实际输出头可微，以及纯FK误差到视觉尾层的梯度。首次100步断点检查保存/加载后的参数输出、Adam moments、CPU/CUDA随机状态精确一致。最终检查实际视觉权重变化。

保留原准入：WiLoR相机与相对好点损坏各≤1%、相机均值非劣0.1mm、相对均值至少改善5%。另要求教师相机/相对好点损坏各≤1%，两种均值相对教师非劣0.1mm。满足门槛还要比较相同协议的冻结对照、难例恢复、配对区间和完整运行结果。

所有最终候选与稳定输出先冻结，再读取复测标签。比较原准入模型、三个固定最终步模型与保护组准入权重；报告恢复/损坏计数、按序列配对95%区间、骨长、跳变、快速动作幅度及自然RGB失败图。v46的10片段已经使用过，只是诊断复测，不是独立泛化证据；高误差分组不等同于逐指遮挡真值。

## 冻结对照完成、joint对照开始

冻结组也完成累计2400步。最终开发集相机/相对误差39.741/16.322mm，WiLoR相机/相对好点损坏26/469、2/650；教师好点损坏6/588、0/1539。相机保护未达标，全部训练断点没有通过完整开发准入，best.pt保留原准入教师，best_trained.pt的800步只用于诊断。

相同总预算下，冻结组均值更低，但相机好点损坏5.54%，保护组为0.85%。两组阶段一权重不同，教师保护的直接效果仍要与同起点的joint组比较；joint已启动。记录这些开发结果，不作为最终稳定输出、置信区间或泛化结论。

## 同起点中途对照与下一轮依据

joint和protected确认相同初始权重、批次计划。续训1300步时，joint相机/相对误差39.134/16.315mm，WiLoR相机好点损坏37/469，教师相机好点损坏8/588；protected为44.435/16.729mm、4/469、0/588。相对坏点恢复分别1834/3589与1726/3589。开发集上新增保护减少损坏，也牺牲了均值与恢复；joint继续按原预算训练，不中途修改配置。

仅训练2526中心的覆盖审计：1800步原计划中，533步没有WiLoR相机好点、408步没有教师相机好点、353步两类都没有；3600个微批次中，两类都没有的为1604。相对高误差（WiLoR均值>40mm）训练窗口250个，其中106个同时存在至少一个相机好点。

候选下一轮改动是平衡好点保护、高误差和普通样本的训练采样，保持损失与准入门槛，安排同起点、同预算的均匀采样对照，先小规模验证。完整v48复测后再决定是否优先执行。上述统计只描述保护标签可用性，不代表hinge一定激活，不是逐指遮挡真值；未读取开发/复测标签来定义采样池。证据：`training_coverage_audit.json`、`matched_development_interim.json`。
