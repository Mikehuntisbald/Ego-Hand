# v49 模块贡献消融

本轮按用户要求开展一次有限的消融任务，不恢复 hot3d 定时任务，不替换默认流水线。

先固定 v48 protected/best 的候选和评估输入，逐项移除候选时序选择、RGB辅助项、可靠性权重、整段预平滑/软时序损失、硬运动约束；补充候选均值、固定单候选和不经过求解器的输出。保留原限值做检查；去约束组只能作为诊断，不作为安全版本。原WiLoR、联训前教师及v48三组完整输出为参照。

RGB屏蔽、仅当前帧、空间特征均值先做网络依赖性测试。这些会改变输入分布，不能冒充重训消融。已有v43同配方DiT/回归训练与v48同起点教师保护对照单独列出，不能混合不同数据范围的均值。v48冻结组起点不同，不能独自证明微调贡献。

所有推理只读无GT输入；先封存所有结果及SHA256，再读取复测标签。报告中心相机/相对误差、按序列配对95%区间、高误差组恢复、原准确点损坏、跳变、骨长和快动作幅度。展示移除模块后改善与恶化的真实RGB图。复用10已使用片段/5序列/2已见受试者，只能描述诊断贡献，不作新泛化结论；高误差组不是逐指遮挡真值。

训练模块（RGB、时间、空间、保护与运动监督）需要在相同起点、批次计划、预算下重训。后续训练实验与固定权重拆除实验分开记录，不把输入屏蔽等同于模块收益。

## 同起点续训消融

9组全部从v47 joint600同一检查点开始、同一批次计划、每组续训1800步，累计2400步；有效批量4，损失与训练样本保持一致，只移除指定模块。完整联训和去教师保护两组严格匹配，直接复用v48实际最终步，避免重复花GPU。新训7组：同起点冻结主干、去WiLoR保护、去全部保护、去动作监督、去额外RGB、只看当前帧、RGB空间特征取均值。去额外RGB仍保留WiLoR粗3D（前端本身用过RGB）；它不是完全无图像信息的方法。

每组先跑同一100步机械预检，验证GT无泄漏、恢复状态、头更新、视觉尾层实际更新/冻结及FK缓冲不变，再按固定预算续训；不根据初步精度筛掉消融组。同一已训练起点意味着这是“移除模块后适应”的贡献研究，不等同从零训练。匹配的是更新数和样本曝光；不同组GPU耗时不同，不声称等计算预算优势。固定最后1800步做封存回放；未准入权重只用于消融诊断。

第二目录：`/mnt/why/HOT3D/experiments/trained_module_ablation_v49_20261007`。控制器等待第一批推理消融完成后，单GPU3串行执行；异常保留日志与完整optimizer/RNG断点。`sync_ablation_v49.py --watch`只同步这一次实验，完成/异常即退出，最多12小时，不注册或恢复定时任务。

## 已完成的拆除诊断

19组推理消融完成；3760检测观测、560有效中心、10640非腕中心点、5序列。追加2组手模型对照另列，避免把手模型拟合收益算给DiT。WiLoR相对误差33.130mm，200步GT-free手模型拟合29.048mm，拟合＋稳定器28.952mm，完整保护DiT＋稳定器28.006mm；后两者差值的序列配对95%区间为[0.521,1.348]mm。

原始DiT时序候选输出123/2864对伪跳变，完整稳定器0/2864；去求解器运动项118/2864。去可靠性权重，相机好点损坏21/743→127/743，相对好点4/267→10/267。去预平滑＋软时序、保留硬约束时误差38.619mm且动作幅度仅50.8%，有明显耦合，不能把变化归给单个软损失。取消硬约束有9对跳变，并且原运动限制检查失败。完整快动作幅度74.8%，去全部求解器运动项98.0%；稳定与幅度有代价。

额外RGB输入屏蔽增加相对误差0.645mm，CI[0.416,0.943]；空间特征均值增加1.079mm，CI[0.663,1.536]。仅当前帧变化-0.133mm，CI[-0.393,0.009]；逐帧候选选择变化-0.052mm，CI[-0.285,0.126]。后二者没有支持明显时序收益；这些输入删除只是依赖性/分布外诊断，重训表另报。

遇到的核验问题：CPU与GPU的浮点误差会改变接近并列的候选索引，所以不以跨后端索引精确相同作为标准。改为同一GPU核验：所有开关开启时，新旧求解器及原v48已封存结果逐元素完全一致，最大差0mm；删求解器项的各组候选路径也精确相同。核验仅短暂停住本任务自己的控制器，当前训练子进程先完成100步，没有中断或改变优化器/RNG；结束后控制器继续。

自然图已生成36张模块对照和6张手模型对照；统一局部放大，保留原整帧图。原始GT与三维输出不变。报告同时给误差、恢复/损伤、序列CI、跳变、骨长和快动作幅度。所有结论属于重复回放探索，未校正多重比较、不作新受试者泛化证据。

7个新增续训组已全部通过100步预检：GT污染输出不变，optimizer/CPU-CUDA RNG恢复精确，时序头实际更新，冻结/无额外RGB组视觉权重精确不变，其他组四视觉块及Norm实际更新，FK缓冲区不变。控制器已开始从各自100步完整断点继续至1800步。冻结的是共同起点已经微调600步的视觉主干，测的是后续1800步视觉微调的贡献。

本地汇总报告：`experiment_reviews/module_ablation_v49_20261007/report.html`；手模型对照：`experiment_reviews/decoder_ablation_v49_20261007/report.html`；重训完成后另同步到`experiment_reviews/trained_module_ablation_v49_20261007/report.html`，不覆盖首批拆除报告。第一份汇总同时保留旧v43严格匹配DiT/回归结果，并明确其数据范围与当前回放不同。

## 手套与双手重叠专项覆盖

新审计只读已封存的v48保护组与WiLoR输出。10片段1500帧、40帧人工抽样均见裸手，没有确认的手套测试组或手套标签。只标穿戴者左右两手，不能推广到多人/三手以上。按GT投影框相交面积/较小框面积做代理分层，0.1–0.5为部分重叠，≥0.5为强重叠；不把框交叠当作手指像素遮挡真值。

双手框分开1400帧、536匹配中心：WiLoR/完整相对误差32.722/27.416mm；部分框重叠31帧、11中心209点、2序列：59.154/64.122mm，完整减WiLoR的序列配对CI[-4.185,10.198]，没有支持稳定的手指恢复收益。部分组原相对坏点恢复13/189、原好点损坏0/6，样本过少。投影手匹配覆盖为59/62，分开组2789/2800；该分母含物体遮挡的投影手，不是像素可见手召回率。强框重叠0帧，没有重遮挡实证。
