# v47 开发记录：在线 RGB 与三维时序核心联训

范围：固定 YOLO 手框/轨迹、WiLoR 初始 XYZ 和 200 步 IK；在线编码原始 RGB，联训 WiLoR ViT 最后 4 层、末端 Norm、时序 DiT 参数头。通过现有可微 UmeTrack/FK 计算三维关节点损失。模型几何缓冲区固定。候选选择和 350 步稳定器仍在训练图之外。

空间信息保持 192×1280；17 个近密远疏槽位使用实际时间戳，最大 ±1.6 秒。没有人工遮挡。推理继续使用速度不变、加速度同步×2的配置。

两组对照：冻结视觉主干＋训练时序头，与末端视觉层＋时序头联训。两组都在线编码，使用相同初始权重、批次计划、有效批大小4、600步预算与监督。仅训练原2526个训练中心，352个已使用开发中心选型，包含步0。复测v46已有片段只能算诊断，不能算新的独立泛化验证。

遇到的问题和处理：
- 原 RGB 特征缓存切断了视觉梯度。改为只缓存原始 uint8 裁剪，前向实时编码；冻结的前28层也在线计算。
- RGB末端转FP16可能损失很小的反向梯度。BF16编码后用FP32承载活跃特征；两组采用同样精度流程。
- 原监督对应±4秒窗口，不能直接配新窗口。将已有参数监督先转世界坐标，再按新槽位转换到中心相机；中心GT保持完全一致，参数标签覆盖约96.65%。
- 原风险概率包含旧时间窗口。用同一冻结风险模型在短窗口重算，训练仍按受试者OOF；温度不再调参。
- 旧缓存和在线输出存在小数值差。增加在线冻结对照；初始化最大3D差0.0244mm，GT污染测试输出完全不变。
- 更新RGB可能改变下游置信度与候选证据，混淆比较。风险/选择器/稳定器证据维持冻结原分支，只改变生成器的视觉输入。

已通过：纯FK三维误差可传到第32视觉层；末端4层均有非零梯度；第一步权重变化非零，冻结对照为零。600步训练与最终诊断结果以实验目录summary.json为准。

入口：`complete_hand_tracks_online_v47.py --input tracks.json --output result.json --mode joint --checkpoint best.pt`

`best.pt`遵循开发集保护门槛，可能保留步0；`last.pt`是实际600步训练权重，仅作固定末步实验诊断。默认生产v42未替换。

工程边界：本版实现RGB重建核心在线联训，没有将检测、关联、IK和最终硬约束合并为全链路可微网络。

最终验收：
- 两组600步完成；开发集保护门槛都未过，best.pt均为步0。last.pt是已训练权重，保留作诊断。
- 联训前后末端视觉参数最大变化1.2986e-4；600步实际权重通过16帧真实RGB运行检查，配置速度不变、加速度×2。
- 已评估片段复测：冻结主干600步相机/相对误差38.997/27.708mm；末端联训600步为38.702/27.965mm。快动作保留73.97%→74.88%。
- 相对冻结对照，41/3980个原本≤10mm点变成>20mm；1024/36116个原本>20mm点恢复到≤20mm。高误差组恢复57→50。
- 两版伪跳变、骨长极值、骨长闪烁均为0，保存参数重解码检查通过。两项精度配对95%区间均跨0。
- 核心工程和梯度链已跑通，当前视觉末端联训未可靠超过冻结对照。默认v42未替换。本轮是已评估片段复测，不是独立新片段验证。
