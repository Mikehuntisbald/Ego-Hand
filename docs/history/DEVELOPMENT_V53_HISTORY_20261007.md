# v53 RF-DETR 多数据直接替 YOLO

目标：把 RF-DETR 作为实际手检测器和实例分割前端，保留已验证3D后端。v52裸手mask改善，但手套完整3D未获益，结果另留档。

- 起点：v52选中SegSmall权重（真实EgoHands mask训练），576输入；视觉编码器、检测/分割头一起训练。
- 四源StageA：EgoHands3387训练图（人工轮廓），HOT3D1283（回放×2），Surgical344（真实框×2），CPPE378（手套框×2），合计7397训练采样图；冻结data_stageA，10轮，batch16，无人工遮挡/随机裁剪。
- 像素mask只监督原人工轮廓；框数据忽略mask匹配代价/损失，不把空mask当背景。CPPE未标注裸手，未匹配query不受背景负类监督。
- CPU检查：真实mask路径精确一致，缺mask损失/梯度为0，CPPE未知query分类梯度为0；GPU96图/12步混合检查通过，编码器/框/分类/mask实际更新。
- 首次GPU暴露CPU索引/CUDA bool冲突：错误与源码留errors/mask_index_device，另建r1修复后重验；首次错误发生在optimizer更新前。
- 标准mask AP只在有人工mask的EgoHands验证图计算；其余开发集做框评价，不制造mask真值。
- 每轮用同一EMA、同一在线推理路径做多域开发。阈值与权重只按开发选：HOT3D旧正确手0损失，Ego检出/精确率不降，两个手套域覆盖不降。未过门槛的best_trained不当best_admitted。
- 现有YOLO预测已冻结作对照。旧v51测试为诊断复用；新素材/新组另留出，推理输出先冻结后读标签。最终再测完整3D关键点损伤、轨迹/骨长/运动，不只汇报检测率。
