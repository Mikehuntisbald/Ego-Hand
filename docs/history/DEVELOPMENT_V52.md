# v52 RF-DETR 手实例分割

目标：训练逐手实例分割替代 SAM2，并接现有完整 3D 模型验证。

- RF-DETR 1.11.2 SegSmall，COCO 预训练，576 输入；独立运行环境，避免与 WiLoR 的 Transformers 版本冲突。
- EgoHands 原人工轮廓，精确转为 COCO RLE；训练3387图、验证200图、测试1200图，同步两视角按交互对划分，不人工遮挡。
- 手套 CPPE/Surgical 数据只有框/关键点，不伪造 mask 真值。裸手分割与手套验证分开。
- 小规模96训练/32验证先检验实际梯度、权重更新；通过后训练完整数据。模型选取只用验证，阈值只用验证；测试输出先冻结再评分。
- 替换候选仍输出34参数/UmeTrack FK 3D，保留非因果±1.6秒和原运动约束。逐帧分割不等于物理身份跟踪。

## 问题与修复

1. 独立环境最初没读到系统Torch，pip误认为缺依赖：显式加入只读基础包路径，仅在实验venv安装新依赖，基础环境不改。
2. 远端下载预训练中途限速：保留部分文件/日志，从本地下载并核验官方MD5后传入。尚未训练时重启，不涉及optimizer丢失。
