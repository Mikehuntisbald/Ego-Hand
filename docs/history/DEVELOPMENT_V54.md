# v54：RF-DETR适配与无mask旧版公平比较

正式旧版基线为**原YOLO26＋无instance mask的v43/v48**。补RF框＋同一个无mask v48，单独测检测器替换；v53、v54完整模型另列。带mask的YOLO同预算训练只作辅助对照，不叫原版。

## 问题与处理

- v53检测覆盖改善，但原正确关键点也有损伤；部分与手侧改变同时出现。单独检验“锁定预测轨迹手侧”，不使用GT左右手，不保证错误的初始手侧会被纠正。
- 新框/mask改变RGB裁剪和空间归属。两组从同一v51准入权重开始，一组保留原条件，另一组用封存RF预测重新生成裁剪、空间位置、射线和mask；末四视觉层＋DiT＋FK在线训练。
- 避免把增加训练预算算成模块贡献：同样窗口、外部实例、种子、损失与更新数。每组独立20步机械预检通过后，从共同起点各训160步。固定末步与准入best分开评估。
- 训练用WiLoR/IK初值保持共同原观测；本轮测RGB/mask条件适配，不声称训练初值已全部由RF重建。外部2D训练用相同原3D观测，只替换预测RGB裁剪条件。
- 手套缺3D/物理时序GT：用真实2D/可见性监督；保留HOT3D真实3D与扩散/保护监督，不造3D标签或时间戳。

## 公平协议

同RGB、相机、时间戳、GPU3、BF16、统一框IoU/外观关联器、±1.6秒、4候选/10步DDIM、FK及原速度/软硬加速度×2。v43权重使用共同运行配置，另注明其历史配置不同。旧版重建不输入instance mask，也不调用SAM2；框栅格只算跟踪框IoU。

完整输出全部封存，再读测试标签。漏手计入PCK失败；3D均值只比较双方共同匹配点。报告难点恢复、旧正确点损伤、源序列配对CI、断轨/身份变化、跳变、骨长与快动作幅度。Native GT框由标注3D投影导出，覆盖不是可见像素召回。

10个HOT3D既有片段/5序列/2已见受试者、12个手术图/6源组均为重复诊断；护理120帧无GT身份/3D。不是新泛化验证。原正确点保护门槛不变，未准入last不冒充安全best，默认未换。

远端：`/mnt/why/HOT3D/experiments/rfdetr_fair_3d_v54_20261007`。独立源码快照与控制器；只排队用空闲GPU3，不动其他项目。单次有界任务，不恢复定时跟进。同步入口：`sync_fair_v54.py --watch`。

两组20步GPU机械预检、各160步训练已完成。RF组选第80步、旧条件辅助组选第160步；两者末四视觉块及Norm均实际更新，15个FK几何缓冲不变，保存/重载、optimizer/RNG及GT毒化检查通过。末步与best仍分别评估，完整流程尚未准入。

额外保留原无mask v43权重/v46配置与v48保护版的**已封存原生输出**，原YOLO的0.01/top10、原跟踪与粗重建均保持。统一跟踪器的行只作控制比较，避免改跟踪后把旧版削弱；旧输出和新输出用同一GT规则重评。旧版在外部手套没有历史标定运行，使用统一pinhole适配器，另注明。补充协议在读取新一轮测试标签前记录，原协议与共同运行报告保留。

## 关联预检发现与r1

r0统一关联器的保守margin把一段150帧旧YOLO输出切成158条候选轨迹，短轨逐条拟合开销很大。仅检查预测ID/运行时间，未读本轮测试标签。保留r0源码、输出与日志，不扩大该路径。
