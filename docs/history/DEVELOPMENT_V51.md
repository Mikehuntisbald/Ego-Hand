# v51：完整模型的真实手套、多人物多手适配

只训练、验证完整流程：YOLO26 → 手实例 mask / 离线身份关联 → WiLoR → RGB 时序 DiT → 34 参数 / UmeTrack FK → 整段稳定化。保持 ±1.6 秒上下文、192 空间 token、原速度与软硬加速度 ×2；不造遮挡。2D 标签只做监督，最终仍输出 3D。

## 数据与当前结果

- 已获得真实 EgoHands 4,800 图、原始人工轮廓；按同步反视角交互对划分。CPPE-5 原作者 MD5 通过；Surgical Hands 抽取 553 真实图、1,427 实例。手套数据没有独立 3D GT，也没有可核验的物理时间戳，不能编造时序/深度监督。
- 另有真人 Nail Care 护理视频（蓝手套操作者与患者手交叠）及真实美甲店照片。只有定性素材，不能冒充商业美甲标注集或 3D 真值。
- 冻结后独立留出检测：EgoHands 3,852 实例覆盖 32.6% → 91.4%；CPPE 官方测试 355 手套 0.8% → 60.6%；Surgical 309 手实例 12.9% → 76.4%。开发原域检出保持 151/154。
- 160 步完整 3D/RGB/mask 联训选第 120 步；后 240 步增加 2D 权重的联训全部未通过原正确 3D 点保护，保留诊断权重，不接入。
- 将图像定位监督与单目深度分开：400 步 RGB/mask 定位分支选第 200 步，手套开发 PCK10 17.1% → 64.7%，原域 477 点 PCK10 29.1% → 94.3%，原正确 34 点零额外损伤。只证明定位分支；最终 3D 拟合另验。

## 遇到的问题与解决

1. 外部图片不能支持真实 3D/时间监督：投影与可见性做 loss-only，保持 HOT3D 真实 3D/运动监督，不将 GT/教师喂给推理。
2. 双视角随机分视频会泄漏：同期两视角一起分组，废弃初轮泛化结论，从未见外部数据的权重重训。
3. 零分支改变 BF16 dtype：修复残差 dtype 后精确保持原预测；日志/冻结源码保留。
4. 加强单目 2D 投影牵动 3D 根位置：不放松保护门槛，保留已准入权重；独立训练定位分支，再检验完整拟合。
5. 低分框产生短假轨迹；未来确认之前先丢帧会损失真手：先离线连接再确认，短轨与替代检测全部保留为复核。身份不明不强拼。
6. 可视化直接发现托盘可成为长期假手，两只蓝手套会被合框。时序稳定、SAM2 几何轮廓均不能证明是手；正在补真实背景 hard negative 复核器。实例漏拆仍需验证，不能声称已做好。
7. 控制器路径、numpy bool JSON、定位 stem 与 heat head 权重前缀出现错误：分别修复导入、显式序列化与精确加载；保留旧快照/日志，未覆盖历史。
