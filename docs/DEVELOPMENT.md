# 开发记录：问题与处理

| 遇到的问题 | 处理 | 当前边界 |
| --- | --- | --- |
| 早期输出 2D，不能解决 3D 标注 | 保留旧实验，改成 3D；进一步改为参数＋FK | 2D 热图只做辅助 |
| RGB 对模型贡献小 | 保留全部 192 个空间位置；训练最后四视觉块，核验梯度及真实更新 | 训练通路成立不等于任务收益成立 |
| 相机运动被当作手运动 | 使用相机姿态把附近帧对齐到统一坐标 | 依赖相机标定和外参 |
| 遮挡候选改善部分点，也损坏准确点 | 增加损伤指标、可靠性、loss-only 教师保护，保留严格准入门槛 | 不承诺未知数据零损伤 |
| XYZ 候选飘飞、骨长或时序不连贯 | 网络输出 34 维手参数；FK 后解码；整段共享形状和运动约束 | 稳定的错误深度仍可能发生 |
| 快动作被过度压缩 | 速度不变，软硬加速度限制同时放宽两倍，报告快速运动保留 | 不通过放松准入制造收益 |
| 手套和多手域检出不足 | 增加真实多域检测数据；训练 RF-DETR 框＋实例分割 | 原始数据和许可另行获取 |
| 多手重叠的空间归属混淆 | 加自己/其他实例 mask 和质量，结合原 RGB 空间条件 | mask 不是物理可见性真值 |
| 换 RF 后旧正确 3D 点受损 | 匹配训练预算做 RGB/mask 适配；另测预测手侧锁定 | 完整 v54 对比未结束 |
| 公共关联器切出大量短轨，评估很慢 | 在独立 r1 中恢复原预测运动/IoU 匈牙利关联；同段 158→15 条候选轨迹，观测数不变 | 未用测试分数选择修改；身份准确性待评估 |
| 基线被公共适配器改变 | 额外保留原无 mask v43/v48 的已封存输出，同一评分规则重评 | 公共运行比较与原版输出参考分开 |
| 源码、末步、best 和结果易混淆 | 冻结源码、封存输出、记录 checkpoint 哈希；开发集 best 与未准入末步分开 | 当前 v54 结果标 pending |

详细历史说明保留在 `docs/history/`。当前代码和模型从不可变快照导出，未中断正在执行的有限评估，也未重启旧定时任务。
